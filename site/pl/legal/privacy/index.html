Dane przetwarzane na Twoich komputerach

Gdy odpowiednie funkcje są włączone, Seam przetwarza zdarzenia klawiatury i myszy, tekst lub obrazy ze schowka, nazwy urządzeń, lokalne adresy IP, dźwięk systemowy oraz obraz wirtualnego ekranu Maca (tylko wirtualnego, nigdy wbudowanego ani innych fizycznych ekranów Maca) albo wirtualnego monitora Windows. Te dane są przesyłane tylko między sparowanym komputerem z Windowsem i Makiem w sieci lokalnej, szyfrowane AES-256-GCM. Aplikacja nie wysyła ich treści do nas ani do żadnej chmury.

Sekret parowania jest przechowywany w Pęku kluczy macOS albo zaszyfrowany dla bieżącego konta Windows przez DPAPI. Ustawienia, data rozpoczęcia okresu próbnego, klucz licencji i ostatnie wpisy dziennika diagnostycznego zostają lokalnie na każdym komputerze.

Sprawdzanie aktualizacji

Jeśli sprawdzanie aktualizacji jest włączone (domyślnie; możesz je wyłączyć w Ustawieniach), aplikacja łączy się z API GitHuba i serwerem wydań GitHuba (github.com/pkozubski/seam-releases). GitHub otrzymuje zwykłe dane połączenia, np. publiczny adres IP i identyfikator aplikacji (user agent). Zapytanie nie zawiera danych schowka, sterowania, dźwięku ani licencji. Przetwarzanie przez GitHub opisuje jego polityka prywatności.

Jeśli zainstalujesz sterownik wirtualnego monitora dla aplikacji Windows na Macu, aplikacja Windows raz pobiera z GitHuba wydania Virtual Display Driver i nefcon, sprawdza ich sumy SHA-256 i instaluje je za zgodą administratora.

Licencja Seam Pro

Okres próbny nie wymaga konta ani danych płatniczych. Data jego rozpoczęcia zostaje tylko na Twoim komputerze.

Po aktywacji Seam Pro aplikacja wysyła do License API Lemon Squeezy (api.lemonsqueezy.com):

  • przy aktywacji: klucz licencji i nazwę urządzenia (nazwę komputera ustawioną w macOS lub Windows);
  • przy sprawdzaniu, mniej więcej co 7 dni, gdy komputer jest online: klucz licencji i identyfikator aktywacji otrzymany przy aktywacji;
  • przy dezaktywacji, gdy wybierzesz Dezaktywuj: klucz licencji i identyfikator aktywacji.

Lemon Squeezy otrzymuje przy każdym zapytaniu także Twój publiczny adres IP. Nic więcej, w tym żadne dane z poprzednich punktów, nie jest wysyłane. Gdy sprawdzenie się nie uda, Pro działa do 30 dni od ostatniego udanego sprawdzenia.
